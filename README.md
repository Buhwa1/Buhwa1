## 🚀 Featured Work

### 🎁 Loyalty & Rewards Platform (SaaS)
A multi-business loyalty card system for retail shops and restaurants. Customers earn and redeem points by scanning a QR code or giving their phone number, and each business manages its customers, rewards and activity from a web dashboard.

**Built with:** React, TypeScript, Supabase (Postgres, Auth), Mobile Money integration
**Highlights:** multi-tenant data model, QR and phone-number identification, subscription-based SaaS model for SMEs

![Loyalty dashboard](./assets/loyalty-dashboard.png)

### 📞 [BuzzTime](https://buzztimeapp.com)
A parent–student calling platform used by schools across East Africa, with a web side for schools and mobile apps for calling.

**Built with:** React, React Native, Firebase FCM, ZegoCloud / Twilio Voice, CodePush OTA updates

![BuzzTime](./assets/buzztime.png)

### 🛠 BuzzTime Support Tool
A hosted web app that gives field agents step-by-step troubleshooting guides, each with its own shareable deep link.

**Built with:** React, Vite

### 🏛 Renderform
A SaaS web app for AI-powered architectural visualisation.

**Built with:** full-stack web (frontend and backend), AI image generation pipeline

![Renderform](./assets/renderform.png)

### 📱 Android Device & POS Systems
- **BuzzTime Monitor:** an Android MDM/kiosk app using Device Owner mode, silent APK installs, OTA updates and WebRTC screen casting.
- **BuzzTime POS:** a point-of-sale app with fingerprint (ZKFinger) integration, built for low-end Android hardware.

> Much of this work is proprietary, so the code isn't public. I'm happy to walk through architecture and decisions in an interview.
